# Expense Tracker App 🚀

A full-stack Expense Tracker application built using:

- ASP.NET Core Web API
- React + Vite
- SQL Server
- Entity Framework Core
- JWT Authentication
- Refresh Tokens
- Tailwind CSS

---

# Features

## Backend
- Clean Architecture
- JWT Authentication
- Refresh Token Authentication
- Expense CRUD APIs
- Category Management
- Budget Management
- Analytics APIs
- Global Exception Middleware
- Fluent Validation
- SQL Server Database

## Frontend
- React + Vite
- Tailwind CSS
- Protected Routes
- Dashboard UI
- Expense Management
- Budget Tracking
- Analytics Charts

# Setup Instructions

## Backend

```bash
dotnet restore
dotnet ef database update
dotnet run
```

## Frontend

```bash
cd frontend
npm install
npm run dev
```
